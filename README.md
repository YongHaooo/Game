Overview
This is a game created using MIT Scratch.
The game focuses on helping new smrt staff train their reaction time and is designed to be simple, interactive, and engaging.
How to Play
Click the green flag to start the game.
Use the following controls:
[left Key] – [move left]
[Right Key] – [Move right]
Fix [obstacle] and try to [Fix as many obsticles as possible].
The game ends when [you run out of time and lose or fix a certain amount of obsticles to win].
Features
Clear objective and rules
Timer or score system 30 seconds timer each obsticle fixed = 1 point
Restart button
Custom sprites and backgrounds
Sound effects or background music (if included)
